# Мои задачи

Приложение на PyQt6 для создания задач.

## Запуск

pip install PyQt6
python main.py

## Функции

- Ввод названия и описания
- Выбор приоритета (Низкий / Средний / Высокий)
- Дополнительные настройки (Важное, Уведомить, В избранное)
- Список задач
- Кнопки: Добавить, Очистить, Удалить последнюю
- Статус и счётчик задач
