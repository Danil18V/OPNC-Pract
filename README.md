Чат на сокетах (Python)

Это курсовой/лабораторная работа: простой чат-сервер на Python. Работает через TCP-сокеты, поддерживает много пользователей за счет потоков (threading).

 Что умеет

- Подключаться и задавать имя (`JOIN`).
- Писать сообщения всем сразу (`TEXT`).
- Смотреть список тех, кто сейчас в чате (`LIST`).
- Корректно выходить (`QUIT`).

 Файлы в проекте

- `server.py` — сам сервер.
- `client.py` — клиент (чтобы подключаться и писать).
- `protocol.py` — функции для упаковки и чтения сообщений (чтобы сервер и клиент понимали друг друга).
